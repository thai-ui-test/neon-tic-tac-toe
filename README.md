# Neon Tic Tac Toe

A stylish web-based Tic Tac Toe game with a neon arcade look, animated background, score tracking, and a polished responsive UI.

## Features

- Two-player local Tic Tac Toe gameplay
- Win and draw detection
- Scoreboard for X, O, and draws
- Reset round and reset score controls
- Neon glassmorphism design with animated background effects
- Responsive layout for desktop and mobile

## Setup

```bash
npm install
```

## Run locally

```bash
npm start
```

Open the displayed URL in your browser. The default VM port is `8091`.

## Build

```bash
npm run build
```
